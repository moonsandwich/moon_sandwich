# 릴스 공구 디자인 스킬

## 상태: 레퍼런스 분석 미완료
- 레퍼런스: https://www.instagram.com/reel/DdYjj-UPfXE/
- 세션 환경에서 instagram.com 접근이 차단되어(ENOTFOUND) **영상을 직접 보지 못했다.** 아래 "레퍼런스 분석" 칸은 비어 있으며, 추측으로 채우지 않는다.
- 채우는 방법: 사용자가 릴스 캡처(훅 첫 1초, 중간 자막 장면, 마지막 CTA 장면), 캡션 전문, 사용 폰트명(알면)을 전달 → 아래 칸을 채우고 이 상태 문구를 삭제한다.

## 레퍼런스 분석 (채워야 할 항목)
| 항목 | 기록할 내용 | 확인된 값 |
|---|---|---|
| 훅 (0~3초) | 첫 화면 문구, 유형(질문/숫자/결핍/반전), 화면 구성 | 미확인 |
| 폰트 | 제목/강조/본문 폰트, 굵기, 크기 비율, 외곽선·그림자 | 미확인 |
| 색 | 텍스트색, 강조색, 배경 처리(박스/그라데이션) | 미확인 |
| 텍스트 감도 | 줄 길이, 줄바꿈, 이모지 사용, 한 화면 글자 수 | 미확인 |
| 어투 | 존댓말/반말, 문장 종결, 말버릇, 감탄사 | 미확인 |
| 편집 리듬 | 컷 길이, 자막 등장 타이밍, 전환 | 미확인 |
| CTA | 문구, 위치, 링크 유도 방식(프로필/댓글/DM) | 미확인 |

## 일반 원칙 (이 릴스에서 확인된 것 아님, 기본값)
- 훅은 첫 1~2초 안에 "누구에게 / 무슨 이득"이 보이게. 자막은 화면 중앙~상단, 안전영역(상하 약 15%) 피하기.
- 자막 한 장면 2줄 이내, 한 줄 12자 안팎, 강조 단어 1개만 색/굵기로 강조.
- 폰트는 가독성 우선(한글 고딕 굵은체 계열), 2종 이하. 상업 이용 가능 라이선스 확인 필수.
- 공구 필수 정보는 숨기지 말 것: 가격, 공구 기간, 수량/마감, 배송 시기.
- 레퍼런스 분석이 채워지면 이 기본값보다 **레퍼런스 값이 우선**한다.

## 입력 → 산출물 워크플로
사용자가 영상/사진/정보를 주면:
1. **입력 점검**: 상품명, 공구가/정가, 기간, 수량, 배송일, 구매처 링크, 혜택, 주의사항. 빠진 필수 값은 추측하지 말고 질문한다.
2. **릴스 구성안**: 훅 문구 3안 → 장면별 자막(시간 표기) → 캡션 → CTA.
3. **공구 링크 페이지**: 모바일 우선 단일 HTML. 구성 = 훅 헤드라인 / 대표 사진 / 핵심 혜택 3개 / 가격·기간(마감 카운트다운) / 구매 버튼(상단 고정) / FAQ / 유의사항.
4. 톤은 레퍼런스 분석의 어투 칸을 따른다. 과장·허위(최저가, 100% 등 근거 없는 표현) 금지.
5. 결과는 이 저장소에 파일로 저장(예: `gonggu/<상품명>/index.html`)하고 변경 내용을 요약한다.
